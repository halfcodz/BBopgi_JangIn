# 뽑기장인 🧸

실제 인형뽑기방을 그대로 옮겨 온 **3D 인형뽑기 연습 게임**입니다. (Godot 4.7, Jolt Physics)
손님이 되어 뽑기 연습을 하고, 사장님이 되어 기계 세팅을 직접 바꿔 볼 수 있어요.

## 가게 구성
| 구역 | 내용 |
|---|---|
| 큰 인형뽑기 9대 | **1회 1,000원**, 3발 큰 집게 (인형·큰 머리 마스코트(냥이·토끼) / 피규어 박스 / 무선 이어폰·보조배터리·미니 선풍기·블루투스 스피커·무드등 경품) |
| 작은 인형뽑기 10대 | **1,000원 2회**, 작은 집게 (인형·키링 / 키캡 키링 / 말랑이(식빵·복숭아·냥발) / 팝잇 / 슬라임 컵, 2버튼 기계 포함) |
| 일본식 UFO 피규어 존 | 두 칸짜리 흰색 기계 2쌍(4칸). 둥근 헤드·LED 눈·은색 파이프·긴 > 모양 팔의 UFO 집게, 봉(다리) 세팅 |
| 지폐교환기 | 10,000원·5,000원 → 1,000원권 |
| 캡슐뽑기 4종 | 500원~2,000원, 손잡이를 돌리면 캡슐이 굴러 나옴 |
| 나의 전시실 | 가게 안쪽 금색 문 너머 따로 있는 방. 뽑은 인형이 유리 진열장에 실제 모습으로 진열 + 기록판 |
| 음료 자판기 | 실제 자판기처럼 조명 진열창(캔·페트병 견본 24개, 가격표·선택 버튼·품절 표시), 금액 표시창·지폐/동전 투입구·카드 단말기, 꺼내는 곳. 1,000원에 사서 마시기 |
| 사장님 카운터 | 사장 모드 진입, 매출 모니터, 신상 입고 박스 |

## 조작법
- 걷기: `WASD` · 달리기 `Shift` · 점프 `Space` · 앉기(누르는 동안, 앉아서 걷기) `Ctrl` · 둘러보기 마우스 · 상호작용 `E`
- 인형뽑기: `B` 1,000원 넣기 / `N` 5,000원 넣기 → `WASD·방향키` 조이스틱 → `Space` 집게 내리기
  - `C` 정면 / 비스듬히 / 가까이 시점, 마우스로 고개 돌리기, `E` 배출구에서 꺼내기, `Q`·`Esc` 나가기
  - 2버튼 기계: `D`(또는 `X`) 누르는 동안 → 오른쪽, `W`(또는 `Space`) 누르는 동안 ↑ 안쪽, 떼면 바로 하강
- `F1`/`Tab` 사장 모드 · `I` 내 수집함 · `H` 도움말 · `Esc` 메뉴(볼륨·감도·저장·초기화)

## 아이폰(휴대폰) 조작 – 아주 단순하게
- **걷기**: 왼쪽 아래 아무 데나 손가락을 대고 밀기(끝까지 밀면 달리기) · 오른쪽 화면을 밀면 둘러보기 · 두 손가락 벌리기 = 확대
- **사용하기**: 기계·자판기·교환기·진열장을 화면에서 **톡** 누르면 바로 사용 (바라보면 오른쪽 아래에 "뽑기 시작" 같은 큰 버튼도 떠요)
- **인형뽑기**: 오른쪽 **큰 버튼 하나**가 상황에 맞게 바뀝니다 → `1,000원 넣기` → (왼쪽으로 집게 이동) → `내리기` → `꺼내기`
  - 작은 버튼은 `시점`, `나가기` 두 개뿐 · 2버튼/일본식 기계는 이동할 때만 `① →` `② ↑`
- **메뉴**: 위 가운데 버튼 하나 – 도움말 · 내 수집함 · 사장 모드 · 소리 · 저장
- 버튼을 누르면 살짝 진동, 홈으로 나가면 자동 저장, 노치·홈 바 피해서 배치
- 휴대폰 최적화: 모바일 렌더러, 60fps, 3D 해상도 80%, 그림자는 플레이 중인 기계만,
  멀리 있는 기계의 인형은 같은 모양끼리 묶어 한 번에 그림(MultiMesh), 움직이지 않는 부품은 재질별로 합침
- PC에서 휴대폰 조작 시험: 실행 인자 `-- --touch` 또는 환경변수 `BBOPGI_TOUCH=1` (마우스가 손가락 역할)

## 아이폰에 설치하기(맥 필요)
1. 맥에 **Xcode**(앱스토어 무료)와 **Godot 4.7**을 설치하고, Godot에서 `편집기 > 내보내기 템플릿 관리`로 템플릿 다운로드
2. Xcode `설정 > Accounts`에 애플 ID 로그인(무료 계정 가능 – 7일마다 다시 설치, 유료 개발자 계정은 1년)
3. Godot에서 이 프로젝트를 열고 `프로젝트 > 내보내기 > iOS` 프리셋(이미 들어 있음)에서
   **App Store Team ID**(10자리, Xcode 계정의 팀 ID)를 입력. 번들 ID `com.halfcodz.bbopgijangin` 이 겹치면 바꾸기
4. `프로젝트 내보내기` → 만들어진 `.xcodeproj`를 Xcode로 열기 → `Signing & Capabilities`에서 팀 선택(자동 서명)
5. 아이폰을 연결하고 아이폰 `설정 > 개인정보 보호 및 보안 > 개발자 모드` 켜기 → Xcode ▶ 실행
6. 처음 실행 시 아이폰 `설정 > 일반 > VPN 및 기기 관리`에서 개발자 앱 신뢰

## 실제와 같은 물리
- **집게**: 발(prong) 하나하나가 실제 강체이고 모터 힌지로 연결돼 있습니다. 집게 힘 = 솔레노이드 힘(모터 최대 토크).
  힘이 약하면 인형 무게에 발이 벌어지며 미끄러져 떨어집니다.
- **줄 흔들림**: 집게는 줄에 매달린 진자(길이가 변하는 진자)처럼 움직입니다.
  θ'' = -(g/L)·sinθ - (a/L)·cosθ - 2(L'/L)·θ' - c·θ' (a: 레일 가속도, L': 줄이 풀리는 속도)
- **와리가리(큰 기계만)**: 흔들리는 박자에 맞춰 레일을 밀면 공진으로 흔들림이 커집니다. 하강 버튼을 누르면 레일은 바로 멈추고
  집게는 흔들리는 채로 내려가며, 인형에 닿으면 집게의 운동량(약 0.35kg)만큼 인형을 밀고 흔들림이 멈춥니다.
  크게 흔들리면 유리벽에 '툭' 부딪혀 튕깁니다. 작은 기계는 줄이 짧고 뻣뻣해 거의 흔들리지 않습니다. 사장 모드에서 끌 수 있습니다.
- **하강 정지/파고들기**: 집게가 인형/바닥에 닿아 줄이 느슨해지면 멈춥니다. 큰 기계 집게는 말랑한 인형 더미 위라면
  자기 무게로 인형을 누르며 3cm쯤 더 천천히 파고들어 발이 인형 틈으로 깊게 들어갑니다(바닥·상자 위에서는 바로 멈춤).
- **인형**: 머리·몸통·팔·다리·귀가 관절로 이어진 래그돌이라 팔·귀에 발이 걸리고, 넘어지고, 굴러갑니다.
  충돌 형상은 겉모습보다 살짝 작아서 발이 털 속으로 파고드는 느낌을 냅니다.
- **정상 드롭**: 꼭대기에 도착하면 설정한 시점에 힘이 빠지는 실제 '확률기' 동작.
- **일본식 다리(橋渡し)**: 피규어 상자(28×20×15cm, 약 0.8kg)는 무거워서 UFO 팔이 100% 힘이어도 통째로 들지 못합니다
  (팔이 버틸 수 있는 무게를 넘으면 팔이 밀려 벌어짐). 봉 간격은 상자 두께보다 2cm 정도만 넓어서 기울어진 상자는
  봉 사이에 걸리고(斜めハマり) 거의 수직으로 서야 빠집니다. 봉 바깥(앞·뒤)은 받침대라 바깥으로는 떨어지지 않습니다.
- **UFO 팔**: 벌린 자세를 스프링처럼 유지해서 상자 위를 누르면 팔이 살짝 꺾이며 집게 무게(약 0.6kg)만큼만 누릅니다.

## 사장 모드에서 바꿀 수 있는 것
- 단계별 집게 힘: 잡을 때 / 올라갈 때 / 정상 도착 / 이동 중, 정상 드롭 시점
- 확률(강집게): 실력 모드 / N판마다 / 매출 기준, 강집게 힘
- 가격: 1,000원당 판수, 5,000원 보너스 판수, 5,000원권 허용
- 제한 시간, 자동 하강, 조작 방식(조이스틱/2버튼), 집게 발 개수(2/3), 발 벌림 각도, 레일·하강·상승 속도, 줄 흔들림, 하강 깊이
- 상품 진열: 원하는 상품을 기계 안에 **클릭해서 놓기 / 오른쪽 클릭으로 빼기**, 랜덤 채우기, 비우기, 정리
- 매출 장부: 매출·판수·배출 수·원가율·순이익, 금고 인출, 연습용 용돈
